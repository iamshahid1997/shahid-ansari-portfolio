# Shahid Ansari — Portfolio

Personal portfolio site of **Shahid Hassan Ansari**, Senior Frontend Engineer — showcasing 5+ years of experience building enterprise dashboards, B2B/B2C e-commerce platforms, learning management systems, and healthcare portals with React, Next.js, and TypeScript.

**Live site:** [yan-liu-s-portfolio-showcase.vercel.app](https://yan-liu-s-portfolio-showcase.vercel.app)

## Sections

- **About** — professional summary and background
- **Projects** — selected work including the Exlr8 dashboard suite (Superadmin, DP, Integrated DP, Physical CP) and the KGeN Kstore e-commerce platform
- **Skills** — React, Next.js, TypeScript, Tailwind CSS, TanStack Query, Zustand, and more
- **Experience** — Kratos Gamer Network, Chaabi, ClaimTherapist, Belong
- **Freelance & Contact** — availability and ways to reach me

## Tech stack

| Layer | Tools |
| --- | --- |
| Framework | React 18 + Vite |
| Language | TypeScript |
| Styling | Tailwind CSS, shadcn/ui (Radix primitives) |
| Forms & validation | React Hook Form + Zod |
| Testing | Vitest |
| Deployment | Vercel |

All portfolio content lives in [`src/data/portfolio.ts`](src/data/portfolio.ts), so text, projects, and experience can be updated without touching component code.

## Running locally

```sh
npm install
npm run dev
```

Other scripts:

```sh
npm run build     # production build
npm run test      # run vitest
npm run lint      # eslint
```
